IDistinguishR redesign: three directions

Each direction below is a live mock using your real wording: the home search, an instructor card and the log in form (with a visible keyboard focus ring and an error message that doesn't rely on colour alone). Every text colour pair is measured against WCAG 2.2 AA (4.5:1 for text, 3:1 for interface shapes); the tables below each mock show the real numbers.

A. Studio WarmB. Clear IndigoC. Terracotta & Sage

A. Studio Warm

The current warm, wooden identity, finished properly

Keeps what already feels like IDistinguishR (paper, wood, brass) but fixes the weak brass text, loads the intended serif, and tightens everything. Lowest risk; familiar to anyone who has seen the site.

Type: Fraunces (headings) + Source Sans 3 (text)

What every direction fixes (from the audit of the live site): the intended fonts never actually load today (visitors get browser defaults); form fields lack programmatic labels (screen readers hear "edit text"); the small brass step numbers fail contrast at 3.26:1; one focus style exists for the whole site; there is no reduced-motion handling; some pages lack a main landmark or an h1. These get fixed whichever direction you pick.
